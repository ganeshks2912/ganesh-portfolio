# Ganesh K S — Portfolio (React + Vite)

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```

- All text lives in `src/data.js` (projects, skills, education, contact). Replace the GitHub/LinkedIn URLs there.
- Hero video: `public/videos/portrait.mp4` (black background blends into the dark theme).
- Deploy `dist/` to Netlify or Vercel.
